PROMETHEE GUI - Setup & Run Instructions (Windows, Command Prompt)
====================================================================

ONE-TIME SETUP
--------------
1. Unzip this folder anywhere.


2. Open Command Prompt (search "cmd" in the Start menu) and navigate
   into this folder, e.g.:
     cd Downloads\PROMETHEE_beta0715

3. Create the virtual environment:
     py -m venv .venv

4. Activate it:
     .venv\Scripts\activate.bat
   The prompt should now start with (.venv) - that confirms it worked.

5. Install the app's dependencies:
     pip install -r requirements.txt


RUNNING THE APP (every time)
-----------------------------
1. Open Command Prompt and navigate into this folder:
     cd Downloads\PROMETHEE_beta0715

2. Activate the virtual environment:
     .venv\Scripts\activate.bat

3. Run the app:
     streamlit run dashboard.py

   Your browser should open automatically at http://localhost:8501
   To stop the app: click the Command Prompt window, press Ctrl+C.
